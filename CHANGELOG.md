# Changelog

The release notes for each version of MatchZy Enhanced (formerly MatchZy Enhanced, ME) are in two places, and they are the same notes:

- **[Changelog in the docs](https://docs.autotournament.gg/reference/changelog/matchzy-enhanced)**: every version, newest first.
- **[GitHub releases](https://github.com/Auto-Tournament/matchzy-enhanced/releases)**: the notes and the zip for each version. Releases before 2.0.0 are titled MatchZy.

The GitHub release is the source of truth. The docs changelog is generated from it, so this file does not repeat the notes.
